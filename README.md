## Deskripsi Proyek

Proyek ini merupakan program sederhana berbasis Python yang digunakan untuk membaca, mengolah, dan menganalisis data nilai mahasiswa. Program dapat membaca data dari file, melakukan perhitungan statistik sederhana, serta menampilkan hasil analisis nilai mahasiswa.

## Tujuan

1. Menerapkan konsep algoritma dan pemrograman Python.
2. Mengolah data menggunakan struktur data list dan dictionary.
3. Menerapkan fungsi untuk memisahkan proses program.
4. Membaca dan mengelola data menggunakan file.
5. Menerapkan penanganan kesalahan (error handling).
6. Melakukan analisis data nilai mahasiswa.

## Fitur Program

1. Membaca data nilai mahasiswa dari file.
2. Menampilkan data mahasiswa.
3. Menghitung nilai rata-rata.
4. Menentukan nilai tertinggi dan terendah.
5. Menghitung jumlah mahasiswa yang lulus dan tidak lulus.
6. Menampilkan hasil analisis data.

## Cara Menjalankan

1. Buka folder proyek menggunakan Visual Studio Code.
2. Pastikan Python sudah terpasang.
3. Buka terminal pada folder proyek.
4. Jalankan perintah berikut:

```bash
python src/main.py
```

5. Program akan membaca data dan menampilkan hasil analisis nilai mahasiswa.

## Pengujian

Pengujian dilakukan menggunakan beberapa kondisi data, seperti:
- Data mahasiswa dengan nilai valid.
- Data kosong.
- Nilai berupa angka.
- Nilai yang tidak valid.
- Data mahasiswa yang lulus dan tidak lulus.

Hasil pengujian dicatat dalam file `tests/test_case.md`.
